# Folder gambar produk

Letakkan semua foto di sini. Setelah menambah/ubah gambar, jalankan:

```bash
npm run sync-img
```

Gambar diurutkan **alfabetis/numerik** (`hijab1`, `hijab2`, …):

| Urutan | Dipakai di |
|--------|------------|
| 1 | Hero kiri, Most Loved #1, Produk 1 |
| 2 | Hero tengah, Most Loved #2, Produk 2 |
| 3 | Hero kanan, Most Loved #3, Produk 3 |
| 4 | Most Loved #4 |

Tidak perlu nama `hijab3.webp` — cukup 4+ file dengan nama berurutan.

### Section OUTER (homepage)

File dengan prefix **`outer`** otomatis muncul di section OUTER:

```
outer1.webp
outer2.webp
outer3.webp
...
```
